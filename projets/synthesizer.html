🎹 LenSymphony - Synthétiseur en Java

🎯 Objectif du projet

L'objectif de ce projet était de développer un synthétiseur logiciel en Java, capable de produire des sons en temps réel, de gérer différentes notes.

👤 Mon rôle dans le projet

Ce projet a été réalisé en équipe. J'ai participé au développement de la logique du synthétiseur(différents types de sons), ainsi qu'à l'intégration des fonctionnalités audio au sein de l'application.

🧠 Compétences développées

  • Programmation orientée objet en Java
  • Manipulation et génération de son
  • Travail collaboratif avec Git
  • Utilisation de Gradle

🛠️ Compétences utilisées

Java Programmation orientée objet Audio Gradle Git Travail en équipe


Ce projet m'a permis de découvrir les bases de la programmation audio, d'approfondir mes connaissances en Java et de travailler sur un projet technique en équipe nécessitant rigueur et coordination.
