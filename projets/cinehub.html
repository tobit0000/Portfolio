🎬 CineHub - Site de gestion de films et séries

🎯 Objectif du projet

L'objectif de ce projet était de développer une application web permettant de gérer un catalogue de films et de séries, avec un système de notation, de comptes utilisateurs et de gestion des droits, à l'aide du framework Laravel.

👤 Mon rôle dans le projet

Ce projet a été réalisé en équipe de quatre personnes. J'ai participé au développement des fonctionnalités backend et frontend, notamment sur la gestion des films et séries, l'affichage des données et l'intégration des vues HTML avec Laravel.

🧠 Compétences développées

  • Développement d'une application web avec Laravel
  • Mise en place d'un système de connexion et d'authentification
  • Gestion des droits utilisateurs
  • Interaction avec une base de données
  • Travail collaboratif avec Git

🛠️ Compétences utilisées

PHP Laravel HTML CSS Base de données Git Travail en équipe


Ce projet m'a permis de découvrir le fonctionnement d'un framework web moderne, d'apprendre à structurer une application MVC avec Laravel et de travailler efficacement en équipe sur un dépôt Git commun.
